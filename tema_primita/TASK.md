# Task: dashboard din CSV

Faci o aplicatie web in care urci un CSV si iti scoate singura tabele si grafice.

## Ce face aplicatia

1. Urci un fisier CSV.
2. Il citeste, vede ce coloane are si curata datele.
3. Iti arata tabele, grafice si cateva cifre importante.
4. Poti sa intrebi ceva in romana despre date si iti raspunde.

## Ce folosim

- Claude Code
- Val Town — baza de date, server si gazduire (cont gratuit)
- Plugin-urile din `PLUGINURI.md`

## Scopul final

Un link public care se deschide si pe telefon. Intri, urci un CSV, vezi dashboard-ul.

## Reguli

- Trebuie sa mearga cu orice CSV, nu doar cu unul pregatit de tine.
- Nu se blocheaza pe date murdare: randuri goale, sume scrise ca text, acelasi nume scris
  in trei feluri, randuri de total intercalate.
- Modelul nu calculeaza numere. El alege *ce* se calculeaza, codul face aritmetica.

## Ce predai

- `PLAN.md` — 10 randuri, scrise inainte de orice cod: ce piese are aplicatia si ce plugin
  face fiecare piesa
- linkul aplicatiei

## Timp

2 ore. Primele 20 de minute sunt pentru plan, nu pentru cod.
